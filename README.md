# ООП — лабораторные работы

Тут лежат мои лабораторные и материалы по предмету "Объектно-ориентированное программирование". 2 курс, язык — C#.

## Что где лежит

- autumn — лабораторные за осенний семестр
- spring — лабораторные за весенний семестр
- Весенний семестр — сами задания к лабораторным
- Осенний семестр — лекции и задания к лабораторным
- Курсовой ООП — задание и титульник

## Как запустить

Открываешь нужный .sln файл в Visual Studio, собираешь (Ctrl+Shift+B) и запускаешь через F5. У каждой лабораторной своя папка и свой .sln.
